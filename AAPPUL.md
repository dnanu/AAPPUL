## Muscle Chains

### Push vs Pull Dominance

| Chain Type | Upper Body                                | Lower Body                            |
| ---------- | ----------------------------------------- | ------------------------------------- |
| **Push**   | Chest, Triceps, Lateral Delts, Lower Back | Glutes, Quadriceps, Adductors, Calves |
| **Pull**   | Back, Biceps, Rear Delts, Forearms        | Glutes, Hamstrings, Abductors, Abs    |

***

## Movement Patterns (Biomechanics)

### Push Movements

| Muscle        | Primary Actions                        |
| ------------- | -------------------------------------- |
| Chest         | Horizontal adduction + elbow extension |
| Triceps       | Elbow extension + shoulder extension   |
| Lateral Delts | Shoulder abduction + internal rotation |
| Lower Back    | Trunk extension                        |
| Glutes (Push) | Hip extension 25% + knee extension 75% |
| Quadriceps    | Knee extension + hip extension         |
| Adductors     | Hip adduction + internal rotation      |
| Calves        | Plantar flexion                        |

***

### Pull Movements

| Muscle        | Primary Actions                        |
| ------------- | -------------------------------------- |
| Back          | Shoulder extension + adduction         |
| Biceps        | Elbow flexion + supination             |
| Rear Delts    | Shoulder abduction + external rotation |
| Forearms      | Wrist flexion                          |
| Glutes (Pull) | Hip extension 75% + knee extension 25% |
| Hamstrings    | Knee flexion + hip extension           |
| Abductors     | Hip abduction + external rotation      |
| Abs           | Trunk flexion                          |

## Volume Control System

### Definitions

| Term        | Meaning                         |
| ----------- | ------------------------------- |
| **MWV**     | Maximum Growth Volume           |
| **NWV**     | Minimum Required Growth Volume  |
| **AMRAP W** | Final high-volume training week |

### Adjustments

| Scenario | Volume Change                 |
| -------- | ----------------------------- |
| MWV      | +2 to +4 sets per muscle/week |
| NWV      | −2 to −4 sets per muscle/week |

## Mesocycle Structure (7 Weeks)

| Week      | Focus                                                    |
| --------- | -------------------------------------------------------- |
| Weeks 1–3 | Volume ↑ / Intensity ↑ (RIR 0 – technical failure)       |
| Weeks 3–5 | Volume ↑ / Intensity capped + supplementation            |
| Week 6    | AMRAP + advanced intensity (dropsets, pauses, half-reps) |
| Week 7    | Deload – 0 sets                                          |

**1 Mesocycle = 49 days**
